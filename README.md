# 💼 Sarvjeet Kumar Portfolio

Welcome to my **Portfolio Project**! 🚀  
This is a Spring Boot-based personal portfolio showcasing my projects, skills, and contact form integration.  

---

## 🌟 Features

- ✅ **Responsive Design** – Works perfectly on desktop and mobile.  
- ✅ **Contact Form Integration** – Powered by Web3Form API.  
- ✅ **Spring Boot + Thymeleaf** – Clean MVC architecture.  
- ✅ **Secure Configuration** – API keys stored in `.env` and **not pushed to GitHub**.  
- ✅ **Fast and Lightweight** – Minimal dependencies, optimized for performance.  
- ✅ **Code Copy Counter** – Track how many times code snippets are copied 💻  
- ✅ **Project View Counter** – Track project views in real-time 👀
