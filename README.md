## 🚀 Project Overview

This is a **Spring Boot Portfolio Project** with contact form integration using Web3Form.  
- Fully responsive front-end using **HTML/CSS/JS**  
- Backend with **Spring Boot** and **Thymeleaf** templates  
- Secure API keys stored in `.env` (not pushed to GitHub)  
- Contact form submissions tracked
